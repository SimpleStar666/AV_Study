## 第 1 步：搭环境 ✅（已完成）

**做了什么**
- WSL2（Ubuntu-20.04，用户 ts）安装 ffmpeg 4.2.7 / ffprobe / ffplay / x264 / v4l-utils
- 下载 mediamtx v1.21.3（GitHub 直连不通，经 gh-proxy 镜像），安装到 /usr/local/bin/mediamtx，配置 /home/ts/mediamtx.yml
- 生成测试视频 /home/ts/test.mp4（testsrc，640×360@15fps，5 秒，H.264，28KB）

**学到了什么**
- ffmpeg 三件套分工：ffmpeg=生产（转换/推流）、ffprobe=检验（只读分析）、ffplay=展示（播放）
- **容器 ≠ 编码**：mp4 是容器（打包格式），H.264 是编码（画面压缩方式）
- 容器码率 vs 视频码率：差值来自 moov 盒等容器元数据开销（短文件占比高，长视频可忽略）
- testsrc 的意义：确定性测试源，不依赖设备，先把链路跑通

**验收结果**：mediamtx RTSP :8554 监听日志 ✅；ffprobe 读出容器/编码/分辨率/帧率 ✅；三问作答 ✅

## 第 2 步：摄像头挂进 WSL ✅（已完成）

**做了什么**
- Windows 安装 usbipd-win（USB/IP 共享服务，需 UAC）
- 绑定并挂载笔记本摄像头：`usbipd bind --busid 1-11` + `usbipd attach --wsl --busid 1-11`
- WSL 安装 usbip 客户端（linux-tools-generic），ts 加入 video 组
- 抓拍验证：`ffmpeg -f v4l2 -input_format mjpeg -video_size 640x480 -i /dev/video0 -frames:v 1 cap.jpg`

**学到了什么**
- v4l2（Video4Linux2）：Linux 摄像头统一接口，`/dev/video0` 是设备文件
- 摄像头能力表：BisonCam 支持 MJPG（压缩）/ YUYV（裸流），IPC 摄像头同理内置编码器
- 调摄像头基本功：先 `v4l2-ctl --list-formats-ext` 查能力 → 显式指定 `-input_format`
- usbipd 原理：USB/IP 协议把 USB 设备变成网络设备，attach 后 Windows 侧暂时失联

**验收结果**：v4l2-ctl --list-devices 无需 sudo ✅；自行抓拍 ✅；三问作答 ✅
